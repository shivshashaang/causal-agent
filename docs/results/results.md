## Validity, kept separate from accuracy

A method is valid when its adjustment set passes the backdoor criterion, overlap is adequate, and its model assumption is not known to fail. For the doubly robust estimator the model-fit assumption cannot be read from the ground truth, so valid means valid as far as the truth can show. The no-tools LLM's method is self-reported.
